# Before publishing this repository

**Start with a private repository if these checks are unresolved.**

- [ ] Confirm that publishing a coursework-derived solution is allowed under the relevant University of Sydney course and academic-integrity rules. Course deadlines being past does not automatically authorize publication of solutions.
- [ ] Confirm public redistribution rights for the original coursework scaffold, images and sample layouts; replace or remove any materials for which permission cannot be confirmed.
- [ ] Confirm that all third-party code and dependencies are represented accurately and that no private student records, credentials, .env files or machine-specific logs are committed.
- [ ] If a permissive open-source release is desired, choose a suitable source-code license **only after** clarifying ownership and asset rights. No repository-wide LICENSE is included.
- [ ] Check the GitHub Actions run after the initial push; its outcome is separate from previously recorded local Windows tests.
- [ ] Optionally add screenshots recorded from the final working version, after checking that they do not reveal personal details.

## Repository scope

This archive deliberately excludes `original_submission/` source snapshots, assignment scoring screenshots, prior draft projects, personal PowerShell output, local `build/` folders and Gradle caches. These are unnecessary for running or building the final version and may contain personal information.
